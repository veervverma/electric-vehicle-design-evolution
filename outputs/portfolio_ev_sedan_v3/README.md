# Portfolio EV sedan V3

College-portfolio system model combining exterior design, skateboard battery packaging, rear e-axle motor and reduction gearbox, inverter, charging unit, suspension, brakes, interior, and exploded technical communication.

## Recommended use

Open `EV_SEDAN_V3_ASSEMBLED_SHOWCASE.3mf` for the color-coded assembly and `EV_SEDAN_V3_EXPLODED_TECHNICAL.3mf` for system explanation.

## Units

Millimeters for STL and 3MF geometry.
