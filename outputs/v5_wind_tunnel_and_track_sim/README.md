# Formula EV V5 — wind-tunnel animation and reduced-order track study

Presentation airflow/underfloor animation plus conceptual qualifying, race-fastest, and race-pace estimates across a 22-round calendar study.

## Recommended use

Open `V5_VENTURI_WIND_TUNNEL_ANIMATION.glb` in the browser gallery and use the CSV/SVG/report for lap-study documentation.

## Units

Times and assumptions are labeled in the CSV/report; GLB is a visual presentation asset.

| File | Format | Purpose |

| [`V5_WIND_TUNNEL_AND_2026_TRACK_SIMULATION.zip`](V5_WIND_TUNNEL_AND_2026_TRACK_SIMULATION.zip) | ZIP | Convenience archive containing the v5 wind tunnel and 2026 track simulation package. |

## Limitations

No solved pressure field or full vehicle-dynamics model. Typical stated uncertainty is about ±2.5% qualifying and ±4% race pace, with additional uncertainty for new circuits.
