# Formula EV V5 — Spa, Silverstone, and Monaco setup study

Track-specific conceptual setup changes and downforce points for three circuits with different speed and load requirements.

## Recommended use

Use the report for narrative and the two CSV files for setup parameters and track-specific downforce data.

## Units

SI units and degrees as labeled in the report and CSV files.

## Files

| File | Format | Purpose |
|---|---:|---|
| [`V5_THREE_TRACK_SETUP_REPORT.txt`](V5_THREE_TRACK_SETUP_REPORT.txt) | TXT | Documentation, assumptions, guide, or report: v5 three track setup report. |
| [`V5_TRACK_SETUP_PARAMETERS.csv`](V5_TRACK_SETUP_PARAMETERS.csv) | CSV | Structured data or manifest table: v5 track setup parameters. |
| [`V5_TRACK_SPECIFIC_DOWNFORCE.csv`](V5_TRACK_SPECIFIC_DOWNFORCE.csv) | CSV | Structured data or manifest table: v5 track specific downforce. |

## Limitations

Starting hypotheses only; not a seven-post, driver-in-loop, tire, energy, or validated track model.
