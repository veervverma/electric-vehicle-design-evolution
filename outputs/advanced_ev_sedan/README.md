# Advanced EV sedan V1

First modular printable fastback sedan with separate structural, body, wheel, suspension, and retaining components.

## Recommended use

Start with `advanced_ev_sedan_print_plate.3mf` for printing or `advanced_sedan_assembled_reference.stl` for inspection.

## Units

Model dimensions are intended as millimeters. Prefer the 3MF print plate when available because 3MF records units.

## Files

| File | Format | Purpose |
|---|---:|---|
| [`advanced_body.stl`](advanced_body.stl) | STL | Separate triangle-mesh part for advanced body; STL does not store units. |
| [`advanced_ev_sedan_kit.3mf`](advanced_ev_sedan_kit.3mf) | 3MF | 3MF print project preserving object structure and millimeter units where authored. |

## Limitations

Educational display model; test fit all moving or retained interfaces before a complete print.
