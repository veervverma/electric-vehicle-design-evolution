# Formula EV V3 — 2022–2025-inspired floor study

Original educational ground-effect interpretation adding twin Venturi paths, inlet fences, floor-edge structures, plank and skids, bib, multi-stage diffuser, strakes, keel, and wake fences.

## Recommended use

Compare the complete car, assembled underfloor, and exploded underfloor GLBs; numbered GLBs isolate every floor element.

## Units

Presentation GLBs; use the full-scale V6 folder for later CFD-preparation units and the print folders for explicit print scale.
