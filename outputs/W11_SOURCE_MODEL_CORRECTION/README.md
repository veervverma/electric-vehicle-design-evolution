# Original W11 model correction

The previous underfloor section and invented top-plan cooling corridors are retired from the lab. They are not accurate representations of the supplied W11 GLB.

Both replacement views load references/mercedec-f1-2020/mercedec-f1-2020.glb directly, using the same coordinate transformation as the original 3D presentation. No substitute floor, duct or repaired shell is drawn.

- Floor / diffuser: original underside, low camera, tunnel hidden. Existing external V2 flow paths may be shown for context. They are unverified legacy results, not a new simulation or reliable downforce prediction.
- Sidepod inspection: original car with transparent materials. No internal flow paths are drawn. The source is a visual exterior asset, not a defined internal cooling domain; radiator, duct walls, pressure-loss and thermal data are unavailable. Transparency does not constitute internal CAD.

The standalone reduced-Re 2D exterior study is retained. It is not used for the replacement underside or sidepod views. A defensible internal cooling simulation requires additional internal geometry and boundary conditions. No new CFD or physical validation was performed in this correction.
