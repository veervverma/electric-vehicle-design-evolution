# Formula EV V5 — separate 55-part STL print release

Every V5 physical part exported separately for slicing, material assignment, selective reprinting, and assembly planning.

## Recommended use

Use `PARTS_AND_MATERIALS.csv` as the authoritative quantity/material list and the numbered files as individual print jobs.

## Units

Millimeters. Confirm scale on import because STL itself does not record units.
