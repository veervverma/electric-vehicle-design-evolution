# Early EV chassis and sedan visual studies

Rendered concept images documenting the transition from a bare skateboard chassis to an assembled sedan package.

## Recommended use

Use the isometric, side, rear, top, underbody, assembled, and exploded PNGs as visual development evidence.

## Units

Images only; no printable geometry is stored in this folder.
