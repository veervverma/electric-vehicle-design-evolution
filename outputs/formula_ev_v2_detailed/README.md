# Formula EV V2 — detailed GLB and rear DRS

Detailed presentation release with named mechanical and aerodynamic systems, individual GLBs, and an animated 28-degree rear DRS flap.

## Recommended use

Start with `FORMULA_EV_V2_COMPLETE_ANIMATED_DRS.glb`; numbered files isolate each major system.

## Units

GLB is unit-aware for viewing; treat scale as an educational model rather than fabrication authority.
